# Akko Studio pour Windows

Version portable : extraire tout le ZIP puis ouvrir **Akko Studio.exe**.

Windows 10 ou 11, 64 bits. Le composant Microsoft Edge WebView2 Runtime doit être présent. L’installateur standard `.exe` prépare ce composant ; le ZIP portable suppose qu’il est déjà installé.

Le clavier doit être branché en USB. Les réglages proposés dépendent de son identification et des fonctions validées pour son modèle. L’audio utilise la sortie Windows choisie et l’entrée du microphone. Les autorisations Windows doivent permettre à l’application d’utiliser le micro.

La version Windows doit être essayée sur une machine Windows avec les périphériques concernés avant distribution publique. La compilation ne valide pas à elle seule le fonctionnement physique des LED ou des sources audio.

Les licences et les notices des composants sont jointes à cette archive.
